# Evidence 2026.2 operating rules

Use docs/evidence_v2.md for the competition workflow. The university is the decision subject.
The conversational agent proposes and explains; local tools calculate and check constraints.
Never fabricate student replies, institutional participation, literature support, capacity, or effects.
The default case is IMIS. Public data is obtained by the system; students provide personal experience only.
Three dimensions remain separate. No unsupported composite TSI. Unknown is not zero.
Task mappings, current teaching and complete study paths must be reviewed before formal coverage.
Private data, interview logs, API secrets and copyrighted PDFs must not be committed.
Run python -m pytest tests -q for this public package. Legacy source requires separately authorized datasets.
